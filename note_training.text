| Tính chất         | Mục đích sử dụng trong test tự động hóa                          |
| ----------------- | ---------------------------------------------------------------- |
| `visible`         | Kiểm tra UI có đang hiển thị đúng, sẵn sàng để thao tác không    |
| `enabled`         | Kiểm tra chức năng có bị khoá không (ví dụ khi form chưa hợp lệ) |
| `editable`        | Kiểm tra trường input có cho nhập không                          |
| `stable`          | Đảm bảo click/hover/fill vào phần tử đang ổn định trên UI        |
| `receives events` | Tránh bị lớp khác che mất nút cần click                          |
